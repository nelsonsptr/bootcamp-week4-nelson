# Tugas Bootcamp Week 4 - Nelson Saputra

## Yang Perlukan
1. Node.js
2. npm
3. Code Editor

## Cara Menjalankan
1. Lakukan git clone
2. Buka terminal
3. Masuk ke directory kalian menyimpan repository ini
4. Install dependency:
    npm install
5. Jalankan aplikasi:
    npm run dev
6. Buka browser dan akses: http://localhost:5173/ atau sesuai port yang tersedia
